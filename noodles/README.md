# Noodles Supervision — GitHub Pages

## Structure

- `index.html` : English
- `fr/index.html` : Français

Upload **both files with the same folder structure** to your GitHub Pages publishing directory.
For a project repository, if the files are at `noodles-supervision/` in the publishing root, the URLs will be:

- `https://<username>.github.io/<repository>/noodles-supervision/index.html`
- `https://<username>.github.io/<repository>/noodles-supervision/fr/index.html`

Language links are relative to the current HTML file, not to the domain. They work on GitHub Pages and when opened locally.

## Before production

- Set the definitive public domain and add absolute canonical and reciprocal hreflang URLs for EN and FR. They are intentionally omitted here to avoid pointing search engines to unlaunched pages.
- Check image rights and third-party portfolio images; external image hosts may block requests.
- Check the mobile and desktop render on the deployed site.
- Ensure GitHub Pages is enabled and publishing from the branch/directory containing these files.
